# Kit de vídeo Keyve

Um editor de vídeo sem painel: você conversa com a I.A. (Claude Code, Codex ou Cursor) e ela monta, revisa e exporta vídeos. Ele faz criativos animados para Reels, TikTok e Shorts e edita vídeos de alguém falando para a câmera, com a marca do seu cliente.

**Guia completo, vídeo de exemplo e download:** [keyve.io/blog/kit-de-video-keyve](https://keyve.io/blog/kit-de-video-keyve)

## Começar

```bash
npm run instalar
npm run checar
```

Depois abra a pasta no Claude Code (ou na sua I.A.) e peça em português, por exemplo: "Faz um criativo de 15 s para Reels da Padaria Pão Bom divulgando o café da manhã."

Instalação passo a passo, estrutura das pastas e perguntas comuns estão no [LEIA-ME.md](LEIA-ME.md). As regras de uso estão em [LICENCAS.md](LICENCAS.md).

O showreel de exemplo (`exemplos/showreel-keyve-15s`) vem sem o vídeo final neste repositório: renderize com o kit ou assista no [artigo](https://keyve.io/blog/kit-de-video-keyve).
